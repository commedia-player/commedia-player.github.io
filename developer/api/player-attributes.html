<commedia-player> attributes ​

AttributeRequiredDescriptionExample
video-formatYesVideo format: equirect-<fieldOfView>-<stereoType>, fisheye-<fieldOfView>-<stereoType> or flat-<stereoType>.<commedia-player video-format="equirect-180-tb" />
posterNoThumbnail shown when the player loads and when playback ends.<commedia-player poster="path-to-poster.jpg" />

video-format ​

Required. One of equirect-<fieldOfView>-<stereoType>, fisheye-<fieldOfView>-<stereoType> or flat-<stereoType>.

  • fieldOfView: 180 or 360 for equirect and between 180 and 270 for fisheye
  • stereoType: mono, lr or tb

See Video Formats.

poster ​

Path to the image shown when the player loads and when playback ends.

timeline-preview ​

Path to the sprite sheet image used to display timeline previews. The image must be a grid of 8 columns by 8 rows of equally sized frames. See Timeline Previews.

default-quality ​

Preferred quality for video file sources, applied when the player first loads. It must match one of the data-quality values of the <source> elements. If omitted, the first <source> is used.

call-to-action ​

The call-to-action attribute adds a button to the player with a label (text) and link (url). See Call to Action.

ui-color ​

UI color of the player, as a hex color string, for example #e74e6c.

passthrough ​

Enables a passthrough mask. Available masks are chroma-key and alpha. See the Passthrough guide.
