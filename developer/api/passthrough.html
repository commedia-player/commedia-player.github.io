Passthrough ​

passthrough ​

PropertyRequiredTypeDescription
enabledNobooleanDefaults to true. Whether the mask is enabled by default.
maskYeschroma-key | alphaThe mask type.

chroma-key mask ​

Additional properties when mask is chroma-key.

PropertyRequiredTypeDescription
colorYesgreen | blueKey color.
lowerThresholdNonumberDefaults to 0.0. Describes a value at which transparency starts. Pixels at or below this value stay opaque.
upperThresholdNonumberDefaults to 0.4. Describes a value at which full transparency is reached. Pixels at or above this value are transparent. Must be greater that lowerThreshold.

TypeScript ​

ts
interface IPassthrough {
  enabled?: boolean;
  mask: 'chroma-key' | 'alpha';
}

interface IChromaKey extends IPassthrough {
  mask: 'chroma-key';
  color: 'green' | 'blue';
  lowerThreshold?: number;
  upperThreshold?: number;
}

interface IAlpha extends IPassthrough {
  mask: 'alpha';
}
