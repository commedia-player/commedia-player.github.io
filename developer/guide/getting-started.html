Getting Started ​

Commedia player is an embeddable web media player built for immersive video. It runs on all platforms, including desktop, mobile and immersive VR. It plays regular flat videos, 180° and 360° equirectangular videos as well as 180° up to 270° fisheye videos, in mono or stereoscopic (side-by-side or top-bottom) layouts, and it ships as a single custom element <commedia-player>.

What you get ​

  • Immersive and flat playback: Flat, equirectangular 180/360 and fisheye video, mono or stereo. See Video Formats.
  • Two source types: Quality-switchable video files, or adaptive streaming (HLS and MPEG-DASH) with fallbacks. See Video Sources.
  • UI color: Customizable UI color. See UI Color.
  • Poster: Display a preview image when the player loads and after playback ends. See Poster.
  • Timeline previews: Show timeline previews when users hover over or scrub through the playback timeline. See Timeline Previews.
  • Call to action: Add a customizable button to the player's end screen. See Call to Action.
  • Chapters: Divide videos into named sections. See Chapters.
  • Passthrough: Blend the video with the real world using chroma-key or alpha masks. See Passthrough.
  • Playback events: Listen to play, pause, timeupdate and more. See Events.

How it works ​

You can configure the player declaratively. The <commedia-player> tag takes attributes for behavior and appearance (such as video-format, poster and ui-color), and its children describe the content: <source> elements for the video and optional <commedia-chapter> elements for chapters.

html
<commedia-player>
  <source ... />
  <commedia-chapter ... />
</commedia-player>

1. Include the script ​

Add the player script to your page:

html
<script async type="module" crossorigin src="https://api.commedia.app/player/commedia-player.js"></script>

DANGER

The script is locked to whitelisted domains. Please contact us to enable your domain. For local development, the script works on localhost and all local network ip ranges.

2. Embed the player ​

Use the <commedia-player> tag and list the video sources as <source> children:

html
<commedia-player poster="path-to-poster.jpg" video-format="equirect-180-mono">
  <source src="path-to-8k-video.mp4" data-quality="8k" type="video/mp4" />
  <source src="path-to-4k-video.mp4" data-quality="4k" type="video/mp4" />
  <source src="path-to-2k-video.mp4" data-quality="2k" type="video/mp4" />
</commedia-player>

The only required attribute is video-format.

WARNING

Do not use more than one instance of the player at a time!

3. Listen to time update (optional) ​

html
<script>
  const player = document.querySelector('commedia-player');
  player.addEventListener('timeupdate', (event) => console.log(event.detail));
</script>
