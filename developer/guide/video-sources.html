Video Sources ​

The player supports two kinds of sources. Only use a single kind of source per player.

Video file sources ​

Use file sources (for example mp4) when you have the same video encoded at several quality levels.

  • Set data-quality on each <source> to define the quality label in the player's quality selection UI. If data-quality is not provided, the filename will be used as the quality name.
  • Each <source> is one quality level for the same content.
  • The order of the <source> elements is the order the quality options will be displayed in the UI.
  • The first <source> is selected by default unless the player has a default-quality attribute.
html
<commedia-player video-format="equirect-180-mono">
  <source src="path-to-8k-video.mp4" data-quality="8k" type="video/mp4" />
  <source src="path-to-4k-video.mp4" data-quality="4k" type="video/mp4" />
  <source src="path-to-2k-video.mp4" data-quality="2k" type="video/mp4" />
</commedia-player>

Choosing the default quality ​

html
<commedia-player video-format="equirect-180-mono" default-quality="4k">
  <source src="path-to-8k-video.mp4" data-quality="8k" type="video/mp4" />
  <source src="path-to-4k-video.mp4" data-quality="4k" type="video/mp4" />
  <source src="path-to-2k-video.mp4" data-quality="2k" type="video/mp4" />
</commedia-player>

The value must match one of the data-quality values.

Device-restricted qualities ​

Add data-supported-only to sources that should only be available on devices that support it:

html
<source src="path-to-8k-video.mp4" data-quality="8k" type="video/mp4" data-supported-only />

Adaptive sources ​

Use adaptive sources (HLS, MPEG-DASH) for adaptive bitrate streaming.

  • Don't set data-quality.
  • If you add multiple adaptive sources, later ones act as fallbacks when the first one isn't supported. For example, MPEG-DASH with an HLS fallback for iPhone.
html
<commedia-player video-format="equirect-180-mono">
  <source src="path-to-dash.mpd" type="application/dash+xml" />
  <source src="path-to-hls.m3u8" type="application/x-mpegURL" />
</commedia-player>
